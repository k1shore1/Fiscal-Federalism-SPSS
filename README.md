# Fiscal Federalism: State Comparison

Group research project, Loyola College, Chennai.

Question: Do the tax contributions of six states differ from the tax devolution they receive?
States: Tamil Nadu, Maharashtra, Kerala, Uttar Pradesh, Bihar, Jharkhand
Data: Union Budget 2025-26 and GST report data, FY 2023-24 (Rs crore)
Methods: Paired-sample t-test and Spearman rank correlation in SPSS
Results: t-test p = 0.499, Spearman p = 0.397. No significant result at the 5% level.
Limitation: Only six states, so statistical power is low.
My role: I ran the SPSS tests for the group.
